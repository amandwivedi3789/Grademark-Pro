# Project Statement

## Problem Statement
Manual management of student marks can be time-consuming and may lead to calculation and record-management errors. GradeMark Pro provides a simple desktop application for maintaining student records and calculating academic performance.

## Scope
The project covers student record management, marks validation, percentage and grade calculation, JSON data storage, and basic class-performance statistics.

## Target Users
Students, teachers, faculty members, and academic staff.

## High-Level Features
- Student CRUD operations
- Percentage and grade calculation
- Dashboard statistics
- JSON persistence
- Input validation
- Automated unit testing
