- [ ] Run `python -m unittest discover -s tests -p "test_*.py"`

- [ ] Add your name, registration/student details, subject and faculty details to the report cover page if required by your course
- [ ] Create/push GitHub repository
- [ ] Submit GitHub link and PDF on the VITyarthi portal according to your course instructions
